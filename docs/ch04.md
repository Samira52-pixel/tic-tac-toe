1. Ошибки в Go возвращают явно: func f() (int, error), затем проверяют if err != nil.
2. panic — аварийное завершение программы при критической ошибке.
3. error — значение с методом Error() string; сообщает об ожидаемой ошибке.
4. error обрабатывают и программа работает дальше; panic по умолчанию останавливает программу.
5. panic("сообщение").
6. Через defer + recover().
7. defer выполняется даже при панике; в нем можно вызвать recover()
8. errors.New("..."), fmt.Errorf("..."), fmt.Errorf("...: %w", err)
9. Своя структура + метод Error() string
10. errors.Is — сравнить ошибку; errors.As — привести к своему типу. Нужно для разной обработки разных ошибок
11. Своя структура ошибки с полями (код, детали) и методом Error(). Дает больше информации об ошибке
12. Вложенные ошибки — цепочка через %w; сохраняют первопричину ошибки при передаче наверх.
