1. Объект - конкретное значение/переменная типа, имеющая данные и методы. В Go роль класса играет структура; объект - её экземпляр. Характеристики: поля (состояние), методы (поведение), уникальность экземпляра.
2. Состояние - значения полей в конкретный момент.
3. Поведение - операции объекта.
4. Принципы ООП: абстракция, инкапсуляция, наследование, полиморфизм.
5. 
6. Структура - составной тип из полей. Нужна, чтобы объединить связанные данные в одну сущность
7.
8. Конструкторная функция - функция NewXxx, которая создаёт и инициализирует структуру
9. Инкапсуляция - данные и методы собраны вместе. Сокрытие - внутренние поля/методы недоступны снаружи. В Go сокрытие делается через строчную первую букву имени.
10. Структура с методами скрывает детали представления данных за понятным API: вызывающий код работает с User, а не с отдельными полями. Это упрощает изменения и повторное использование
11. Столпы абстракции: инкапсуляция, наследование, полиморфизм. Они уменьшают связанность, позволяют повторно использовать код и менять реализации без правки клиентов.
12. Интерфейс - набор методов; тип реализует его автоматически, если имеет нужные методы. Ключевое слово implements не используется.
13.
14. Наследование в Go заменено встраиванием
15. Функция связывается со структурой через приёмник и становится методом
16. Переопределение - метод с тем же именем объявляют во внешней структуре; он перекрывает метод встроенной структуры при вызове через внешний тип
17. Интерфейс как поле - зависимость на поведение, а не на конкретный тип.
18. Публичное - имя с заглавной буквы, приватное - со строчной. Область видимости - пакет
19. Дженерики - параметры типов у функций и типов. Они убирают дублирование кода и сохраняют типобезопасность.
20. Ограничение - интерфейс, указанный в квадратных скобках; он задаёт допустимые типы и операции.
